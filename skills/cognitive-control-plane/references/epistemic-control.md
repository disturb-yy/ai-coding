# Epistemic Control

Use when a factual or causal assumption determines whether an action is sound.

Identify the load-bearing claim, supporting evidence, uncertainty, and a check that could disprove it. Prioritize checks that are cheap relative to the consequence of being wrong. Use current authoritative evidence for time-sensitive facts; check source applicability and date.

Distinguish observations from interpretations. Prefer a discriminating experiment over collecting more undirected evidence. Numeric confidence is optional and needs a defensible basis; qualitative uncertainty is usually sufficient.

A concise decision record contains the conclusion, evidence, material assumptions, and remaining verification. Expose this rationale, not hidden chain-of-thought. An unverified premise blocks dependent decisions, while independent analysis can continue with the limitation stated.

Completion criterion: each assumption needed for the next action is supported, falsified, or handled with an explicit uncertainty bound and verification path.
