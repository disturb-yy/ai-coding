# 认识论控制

当错误假设会主导结果时，使用认识论控制。

## 假设审计

```yaml
assumptions:
  - statement: ""
    confidence: 0.0
    evidence: []
    falsification: []
```

优先处理这些假设：

- 对方案有承重作用
- 证据薄弱
- 验证成本低
- 错误代价高

完成标准：每个承重假设都有证据、不确定性或证伪路径。

## 决策追踪

使用决策追踪，而不是暴露思维链：

```yaml
conclusion: ""
evidence: []
assumptions: []
uncertainty: []
alternative_hypotheses: []
verification: []
```

完成标准：评审者不需要看到隐藏推理，也能理解为什么这个决策合理。
